# ConfigPilot v1.1.1

Documentation correction for the v1.1 release.

- README installation commands now select the latest release without stale pins.
- Update archive examples, reproducible developer-trial instructions,
  troubleshooting and current release summaries.
- Runtime code, terminal output, public API, JSON schema and exit codes are unchanged.

Install the CLI with `npm install --global configpilot`, or add it to project
scripts with `npm install --save-dev configpilot`. Requires Node.js 20+.
